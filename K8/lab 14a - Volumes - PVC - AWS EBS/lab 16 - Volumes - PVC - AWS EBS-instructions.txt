lab 16 - Volumes - PVC - AWS EBS
=================================

1. Create IAM Role for EC2 K8 Node with IAM policy AND then attach it to EC2
   - AmazonEBSCSIDriverPolicy
   
2. Install the AWS EBS CSI Driver

kubectl apply -k "https://github.com/kubernetes-sigs/aws-ebs-csi-driver/deploy/kubernetes/overlays/stable/?ref=release-1.29"

3. Verify the controller and node pods are running in kube-system namespace
You Will see ebs-csi-* pods running (give it a minute)

kubectl get pods -n kube-system 

4. Apply K8 storage class configuation
